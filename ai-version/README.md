# Task API (AI Version)

This directory contains the AI-generated Task API implementation for Stage 7.

## Setup & Run

1. Navigate to this directory:
   ```bash
   cd ai-version
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm start
   ```
4. Access Swagger UI at `http://localhost:3000/docs`.
