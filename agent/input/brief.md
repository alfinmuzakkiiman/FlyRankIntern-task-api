# Build the Agent (FL-07)

## Goal
Build a working personal AI agent using the platform selected in FL-06.

## Tasks
1. Start with a narrow core job and get one complete end-to-end run working.
2. Connect at least one real tool or data source, such as a file, knowledge base, MCP server, connector, or external service.
3. Keep a build log that records what broke, what changed, and what was removed from the plan, with reasons.
4. Record one raw, unedited screen capture of a successful end-to-end run, about two minutes long.

## Deliverables
- A working agent.
- A build log.
- A raw screen recording of a successful run.

## Evaluation Criteria
- The agent completes its core job without manual editing during the run.
- At least one real tool, file, or data connection is used.
- Any deviations from the design specification are documented.
- The build log records real iterations.
- The recording shows the full process from request to result.
